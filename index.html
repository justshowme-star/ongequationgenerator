Getting it into Google Docs
  • Copy as image, click in your Doc, paste (Ctrl/Cmd+V). Works for everything, including piecewise functions, systems and matrices. Resize in Docs if needed.
  • Editable Docs equation: click Copy for Docs equation, then paste it into your Doc (it is wrapped in $ … $ by default; change “Wrap text in” if you prefer another form), or paste it into Insert → Equation without the $ wrapper. Docs converts commands such as \frac, \sqrt, \theta and \choose when you press space after them. If pasted commands stay as plain text, click right after each command and press space.
  • Piecewise, systems and matrices: Docs equations can’t draw these, so Copy for Docs equation copies them as a borderless table instead: a large brace or bracket beside one row per piece. Paste it straight into your Doc. Cells hold plain math text (x², √x, ≤) you can edit, or choose “Docs equation commands” to get text you can turn into Docs equations cell by cell (type Insert → Equation inside the cell). If borders show up, select the table and set the border width to 0.
  • If the image button is blocked by your browser, use Download PNG and insert it via Insert → Image.
